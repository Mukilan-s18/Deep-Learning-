# Deep Learning Experiments

This repository contains implementations for 11 core deep learning lab experiments, accelerated with Apple MPS (GPU).
All datasets utilized are strictly derived from real-world data sources (scikit-learn built-ins, Airline Passengers, Female Births, and Shakespeare text) preventing any reliance on synthetic random data arrays, whilst preserving extreme execution speed.

## Experiments
1. Neural Network from Scratch (Digits)
2. MLP for Classification (Iris)
3. SGD vs Adam Optimization (Breast Cancer)
4. CNN from Scratch (Digits)
5. Autoencoder Dimensionality Reduction (Wine)
6. RNN Sequence Processing (Airline Passengers)
7. LSTM Architecture (Daily Female Births)
8. Variational Autoencoder (Digits)
9. Word2Vec Embedding (Shakespeare Corpus)
10. Generative Adversarial Network (Digits)
11. Mini Project: Anomaly Detection (Breast Cancer)
